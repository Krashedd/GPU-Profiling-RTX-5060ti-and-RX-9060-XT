# Dataset Files

The complete benchmark datasets are intentionally excluded from this
repository because of their size and redistribution considerations.

The benchmark workloads use:

- CIFAR-10 for ResNet-50
- COCO minitrain and validation assets for YOLOv8m
- GLUE SST-2 for DistilBERT

Dataset configuration files, manifests, and preparation metadata are retained
where available. Images, labels, Arrow files, tokenized dataset binaries,
download caches, and other generated dataset assets must be prepared locally.

Refer to the benchmark scripts and configuration files for the exact dataset
paths, preprocessing settings, random seed, batch sizes, and training
parameters.
